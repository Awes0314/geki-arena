# Operations

## Purpose
この階層に配置されたドキュメントは、開発・運用環境およびデプロイ・外部サービス連携に関する仕様を明確に定義することを目的とする。

## Document Structure
この階層に配置されたドキュメントは、以下の構造で整理されている。

- `./environments.md`: 開発・ステージング・本番の各環境構成および環境変数
- `./deployment.md`: デプロイアーキテクチャおよび各環境へのデプロイフロー
- `./external-service.md`: Supabase・Vercel等、外部サービスとの連携に関する定義
- `./git.md`: ブランチ運用・コミット規約・リリースフローなど、リポジトリのGit運用に関する定義
