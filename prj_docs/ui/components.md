# Components

## Layout Components
- ヘッダー、グローバルナビゲーション、フッター、コンテンツエリアで構成する基本レイアウト。
- 認証状態（未ログイン/ログイン済み/運営）によって表示するナビゲーション項目を切り替える。

## Navigation
- グローバルナビゲーション（`overview.md`参照）。
- パンくずリスト: 大会詳細、コース詳細等、階層のある画面で使用する。

## User Display
- 「どのユーザーか」を示す共通コンポーネント。一覧・詳細・ランキング・参加者一覧など、ユーザーを示す全ての箇所で使う。
- 表示要素: アイコン、ユーザー名（表示名）、Rating区分バッジ、（設定されていれば）コースバッジ。Rating区分未設定の場合はRatingバッジを表示しない。
- ユーザー名はプロフィールへのリンクとする。

## Chart Display
- 「どの譜面か」を示す共通コンポーネント（このシステムでは「楽曲」は譜面を指す）。一覧・詳細・作成ページなど、譜面を示す全ての箇所で使う。
- 表示要素: 楽曲名、難易度バッジ、レベル、譜面定数。
- 難易度バッジは、オンゲキの難易度色を踏襲する。

| 難易度 | 色 |
|---|---|
| BASIC | 黄緑 |
| ADVANCED | 黄色 |
| EXPERT | ピンク |
| MASTER | 紫 |
| LUNATIC | 白・黒・グレー |

## Rating Select
- Rating区分を選択する共通セレクト。選択肢・選択中の値をRating Badgeで表示し、プロフィール編集・大会作成等で共通で使う。

## Checkbox Card
- 枠付きでラベル全体をクリックできるチェックボックス（タイトル＋説明）。チェック時は枠と背景をアクセント色にする。一覧の絞り込み・作成フォームのオプションで共通で使う。

## Score Display
- テクニカルスコア、ジャケット画像を表示する共通コンポーネント（楽曲名・難易度は「Chart Display」を使用する）。
- 詳細内訳（最大コンボ数、CRITICAL BREAK数等）は、`score.md`の可視性ルールに従い、提出者本人・運営者のみ表示する。

## Rating Badge
- `RatingClass`（Rating区分）を表すバッジ。プロフィール、ランキング、参加者一覧等で使用する。
- 色は`rating_classes.tier`（系統キー）に応じてコンポーネント側で切り替える。虹以上は同系統を段階（`label`）で細分化する。

## Course Badge
- コースクリアの報酬として付与されるエンブレムSVGを表示するコンポーネント。
- プロフィールでは選択中の1件のみを表示し、ユーザー表示箇所（ランキング等）にも同じ表示ロジックを適用する（`course.md`, `user.md`参照）。

## Tournament Components
- 大会・1v1共通で使用する、課題曲一覧、ランキングテーブル、参加者一覧、提出状況表示などのコンポーネント群。
- 大会の状態（開催予定/開催中/終了）、1v1の状態（募集中/成立/終了）に応じて表示内容・操作可能なボタンを出し分ける。

## Forms
- 大会作成・1v1作成・プロフィール編集等の入力フォーム。
- クライアント側バリデーション（UX向上目的）とサーバー側バリデーション（`design/api.md`参照）を併用する。

## Dialogs
- 参加確認、離脱確認、削除確認等、不可逆または重要な操作の前に確認ダイアログを表示する。

## Feedback
- スコア提出後のフィードバック（ランキング反映、コースクリア演出等、`score.md`のScore Submission Flow参照）。
- トースト通知等、一時的なフィードバック UIを共通化する。
