# Pages

## Home
- ログイン後のダッシュボード。開催中/開催予定の大会、進行中の1v1、未読通知等のサマリーを表示する。

## Login
- userId・passwordによるログインフォーム。
- パスワード再設定（リカバリーコード、`design/authentication.md`参照）への導線を設ける。

## User Profile
- 自身/他ユーザーのプロフィール閲覧（`user.md`のViewing Profile参照）。
- 自身のプロフィールでは編集導線（表示名、アイコン、自己紹介、SNSリンク、Rating区分、表示するコースバッジ）を設ける。

## Score
- スコア提出確認ページ（ブックマークレット実行後に別タブで開く、`score.md`のScore Submission Flow参照）。
- スコア履歴ページ（提出者本人・運営者のみ詳細閲覧可、`score.md`のScore Visibility参照）。

## Tournament
- 大会一覧（開催予定/開催中/終了でフィルタ可能）。
- 大会詳細（基本情報、ランキング、参加者情報、提出状況）。
- 大会作成・編集フォーム。

## 1v1
- 1v1一覧（募集中の対戦、自身が関わる対戦の表示）。
- 1v1詳細（自選曲選択、挑戦/承認操作、結果表示）。
- 1v1作成フォーム。

## Course
- コース一覧（CHAPTERごとの表示）。
- コース詳細（課題曲一覧、クリア条件の概要、挑戦導線）。
- コースクリア演出・エンブレム獲得画面。

## Settings
- 通知設定、表示設定、アカウント設定、UI設定（`user.md`のUser Settings参照）。
- アカウント削除導線。

## Admin
- 運営専用ダッシュボード（`admin.md`参照）。
- ユーザー管理（停止/解除、通報対応）、スコア管理（削除、不正対応）、楽曲・譜面更新、大会/1v1/コースの監督、全体通知配信、操作ログ閲覧。
