# Pages

## Home
- ログイン後のダッシュボード。開催中/開催予定の大会、進行中の1v1、未読通知等のサマリーを表示する。

## Login
- userId・passwordによるログインフォーム（`/login`）。
- パスワード再設定（`/password-reset`、`design/authentication.md`参照）と新規登録（`/register`）への導線を設ける。
- ログイン済みの場合はホームへリダイレクトする。未ログインで他の画面へアクセスした場合は、この画面へ遷移する。

## Register
- userId・password（確認入力あり）による登録フォーム（`/register`）。フォーム表示中のみログインへの導線を表示する。
- 登録完了後は同じ画面でリカバリーコードを1度だけ表示し、「保存しました」のチェック後に、プロフィール初期設定またはホームへ進める。

## Password Reset
- userId・リカバリーコード・新しいパスワード（確認入力あり）のフォーム（`/password-reset`）。成功時は新しいリカバリーコードを1度だけ表示し、保存確認後にログイン画面へ進める。

## User Profile
- 自身/他ユーザーのプロフィール閲覧（`/users/[userNo]`、`user.md`のViewing Profile参照）。過去戦績は、大会・1v1実装までは枠のみ表示する。
- 自身のプロフィールでは編集導線（`/profile/edit`：表示名、アイコン、自己紹介、SNSリンク、Rating区分、表示するコースバッジ）を設ける。保存成功後はプロフィール閲覧画面へ遷移する。
- 登録直後の初期設定（`/profile/edit?onboarding=1`）では、アイコン・表示名・Rating区分のみを表示し、「スキップ」でホームへ進める。
- アイコン画像を選択した直後に、編集画面上のアイコン表示へ反映する。ファイル名は表示しない。

## Score
- スコア提出確認ページ（`/score-submissions/receive`、ブックマークレット実行後に別タブで開く、`score.md`のScore Submission Flow参照）。提出先の選択、提出候補の確認、提出確定を行う。未ログインの場合はログインへ誘導し、ブックマークレットの再実行を促す。
- ブックマークレット提供ページ（`/bookmarklet`。スクリプトの提供と、モバイルブラウザでの登録・実行手順の説明）。
- スコア履歴ページ（提出者本人・運営者のみ詳細閲覧可、`score.md`のScore Visibility参照）。

## Tournament
- 大会一覧（`/competitions`）
  - 状態フィルタ: 「開催予定・開催中」「終了」の2種類（初期選択は「開催予定・開催中」）。
  - 検索: 1つの検索ボックスで、主催者名・大会名・楽曲名のいずれかに部分一致（OR）する大会のみを表示する。
  - 詳細フィルタ（アコーディオンで折りたたみ）:
    - レベル範囲: 課題曲がすべて指定したレベル範囲内である大会のみ表示する。
    - 参加可能のみ: 自身にRating区分が設定されている場合のみ選択可能。Rating制限のない大会も含め、参加条件を満たす大会（終了済みを除く）のみ表示する。
  - 大会カード: 大会名、状態バッジ、開催期間、主催者（ユーザー表示）、参加者数、説明、参加条件（Rating区分バッジ）、課題曲（先頭3曲をChart Displayで表示し、残りは「他n曲」）、自身との関係（主催・参加）。
- 大会詳細（基本情報、参加条件のRating区分バッジ表示、課題曲、ランキング、参加者情報、提出状況）。ユーザーは User Display、譜面は Chart Display で表示する。
- 大会作成・編集フォーム。
  - 入力項目をセクション（基本情報・開催期間・参加条件・課題曲・オプション）ごとに軽く区切る。
  - 制限がある項目は、項目名の下に制限を列挙する。
  - 開始・終了日時の初期値は「現在+30分以降の10分刻み」と「その7日後」。日時選択は10分刻みのみ選択できる。
  - 課題曲の並べ替えは表示順のための機能で、提出時のプレイ順は問わない。
  - 課題曲の検索は「検索」操作を不要とし、条件変更で自動更新する。初期の難易度はMASTER、候補表示は20件。
  - 開催期間の重複エラーは重要なため、通常のエラーとは別の色（警告色）で表示する。
  - 「必須」「任意」は制限の箇条書きに含めない（必須は項目名の*で示す）。
  - 開催日時の日・時・分は横並びにする。
- 大会管理（主催者専用）では、説明の編集・参加者管理・削除に加え、提出状況（誰がいつどんなスコアで提出したか、曲ごとのテクニカルスコアを含む）を表示する。曲ごとのテクニカルスコアはランキング算出に用いる値であり、内訳属性（最大コンボ数等）は表示しない。

## 1v1
- 1v1一覧（募集中の対戦、自身が関わる対戦の表示）。
- 1v1詳細（自選曲選択、挑戦/承認操作、結果表示）。
- 1v1作成フォーム。

## Course
- コース一覧（CHAPTERごとの表示）。
- コース詳細（課題曲一覧、クリア条件の概要、挑戦導線）。
- コースクリア演出・エンブレム獲得画面。

## Settings
- 通知設定、表示設定、アカウント設定、UI設定（`user.md`のUser Settings参照）。
- アカウント削除導線。

## Admin
- 運営専用ダッシュボード（`admin.md`参照）。
- ユーザー管理（停止/解除、通報対応）、スコア管理（削除、不正対応）、楽曲・譜面更新、大会/1v1/コースの監督、全体通知配信、操作ログ閲覧。
