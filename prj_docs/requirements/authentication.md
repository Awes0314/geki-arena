# Authentication Requirements

## Registration
ユーザー登録を行う機能。
- ユーザーID、パスワードを入力して登録する。
- 個人情報を取得しないため、メールアドレスなどの入力は不要である。
- ユーザーIDは一意である必要がある。
- 各ユーザーには一意のユーザーNoが割り当てられる。
- 初回登録時、表示名とアイコン画像の設定が求められる。（スキップ可能、後から編集可能）

## Login
ユーザーがシステムにログインする機能。
- ユーザーIDとパスワードを入力してログインする。
- パスワードが正しい場合にのみログインが成功する。
- ログイン状態はセッションとして管理される。

## Logout
ユーザーがシステムからログアウトする機能。
- ログイン中のセッションを終了する。
- ログアウト後は再度ログインが必要となる。

## Account Deletion
ユーザーが自身のアカウントを削除する機能。
- アカウント削除を行うと、ユーザーIDおよび関連するデータがすべて削除される。
- アカウント削除後は再度同じユーザーIDで登録することはできない。

## Account Suspension
管理者がユーザーのアカウントを一時的に停止する機能。
- アカウント停止を行うと、ユーザーIDおよび関連するデータは保持されるが、ログインや利用が制限される。
- アカウント停止中は再度ログインすることはできない。
- アカウント停止を解除することで、再度利用可能となる。

## Session
ユーザーのログイン状態を管理する機能。
- セッションはユーザーがログインしている間のみ有効である。
- セッションが切れると、再度ログインが必要となる。
- 再ログインの頻度を減らすため、セッションの有効期限は長めに設定される。
