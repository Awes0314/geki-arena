# Authentication Requirements

## Registration
ユーザー登録を行う機能。
- ユーザーID、パスワードを入力して登録する。
- 個人情報を取得しないため、メールアドレスなどの入力は不要である。
- ユーザーIDは一意である必要がある。半角英数字とアンダースコア（`a-z`, `0-9`, `_`）の3〜20文字とし、大文字小文字は区別せず小文字に正規化して扱う。
- パスワードは8〜128文字とする（文字種の制限なし）。
- 各ユーザーには一意のユーザーNoが割り当てられる。
- 登録時点の表示名はユーザーIDとする。
- 登録完了後、パスワード再設定用のリカバリーコードを1度だけ表示する。ユーザーが保存を確認してから次の画面へ進める。
- 初回登録時、表示名・アイコン画像・Rating区分の設定を促す。（スキップ可能、後から編集可能。自己紹介・外部SNS・コースバッジは初回設定では扱わない）
- 登録完了後は自動的にログイン状態となる。

## Login
ユーザーがシステムにログインする機能。
- ユーザーIDとパスワードを入力してログインする。
- パスワードが正しい場合にのみログインが成功する。
- ログイン状態はセッションとして管理される。
- 未ログインの状態でログイン・新規登録・パスワード再設定以外の画面へアクセスした場合は、ログイン画面へ遷移する。

## Password Reset
パスワードを忘れたユーザーが、リカバリーコードを用いてパスワードを再設定する機能。
- ユーザーID・リカバリーコード・新しいパスワードを入力する。
- 再設定に成功すると、新しいリカバリーコードが発行され、1度だけ表示される。以前のコードは無効となる。
- 失敗時は、ユーザーIDの存在有無を推測されないよう、理由を区別せず同一のメッセージを表示する。
- 停止中・削除済みのアカウントは再設定できない。

## Logout
ユーザーがシステムからログアウトする機能。
- ログイン中のセッションを終了する。
- ログアウト後は再度ログインが必要となる。

## Account Deletion
ユーザーが自身のアカウントを削除する機能。
- アカウント削除を行うと、ユーザーIDおよび関連するデータがすべて削除される。
- アカウント削除後は再度同じユーザーIDで登録することはできない。

## Account Suspension
管理者がユーザーのアカウントを一時的に停止する機能。
- アカウント停止を行うと、ユーザーIDおよび関連するデータは保持されるが、ログインや利用が制限される。
- アカウント停止中は再度ログインすることはできない。
- アカウント停止を解除することで、再度利用可能となる。

## Session
ユーザーのログイン状態を管理する機能。
- セッションはユーザーがログインしている間のみ有効である。
- セッションが切れると、再度ログインが必要となる。
- 再ログインの頻度を減らすため、セッションの有効期限は長めに設定される。
