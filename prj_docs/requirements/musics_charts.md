# Musics / Charts Requirements

## Overview
- 当システムで使用される楽曲および譜面に関する要件を定義する。

## Premise
- 運営者が他システム（Pongeki）で使用している楽曲および譜面の情報を本システムでも使用することを前提とする。
- Pongekiは譜面（CHARTS）単位でのみデータを管理しており、楽曲単位のデータは持たない。当システムの楽曲は、同一楽曲に属する譜面から導出する。
- 当システムの画面上では、楽曲名・難易度・レベルを常にセットで扱い、楽曲名のみで譜面を示すことはしない。

## Musics
- 当システムで使用される楽曲の情報。
- 保持する属性は以下の通りである。
  - 楽曲ID（Pongeki由来の譜面IDから導出する識別子）
  - 楽曲名
- ジャケット画像URLは、同一楽曲でも譜面ごとに異なる場合（LUNATICのみ異なる、Perfect Shining!! のレベル0とレベル13+で異なる等）があるため、譜面側で保持する。
- アーティスト名・ジャンルはPongekiから取得できないため、保持しない。

## Charts
- 当システムで使用される譜面の情報。
- 楽曲ごとに、難易度種別（BASIC / ADVANCED / EXPERT / MASTER / LUNATIC）とレベル表示値の組み合わせ単位で存在する（同一楽曲・同一難易度でもレベルが異なる譜面が存在し得る。例: Perfect Shining!! のLUNATIC）。
- 保持する属性は以下の通りである。
  - 譜面ID
  - 対象楽曲（Music）
  - 難易度種別
  - レベル表示値
  - 譜面定数
  - ジャケット画像URL
  - 有効/無効（Pongekiで削除された譜面は無効とする）

## Update
- 楽曲および譜面情報の更新に関する要件。
- 運営者ページより、手動で更新用処理を呼び出す。
- Pongekiで削除された譜面は、過去の提出が参照している可能性があるため、物理削除せず無効として扱う。
- 取得元・マッピングの詳細は`design/pongeki-sync.md`を参照。
