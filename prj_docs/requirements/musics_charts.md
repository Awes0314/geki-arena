# Musics / Charts Requirements

## Overview
- 当システムで使用される楽曲および譜面に関する要件を定義する。

## Premise
- 運営者が他システム（Pongeki）で使用している楽曲および譜面の情報を本システムでも使用することを前提とする。

## Musics
- 当システムで使用される楽曲の情報。
- 保持する属性は以下の通りである。
  - 楽曲ID（Pongeki由来の識別子）
  - 楽曲名
  - アーティスト名
  - ジャケット画像URL
  - ジャンル

## Charts
- 当システムで使用される譜面の情報。
- 楽曲ごとに、難易度種別（BASIC / ADVANCED / EXPERT / MASTER / LUNATIC）単位で存在する。
- 保持する属性は以下の通りである。
  - 譜面ID
  - 対象楽曲（Music）
  - 難易度種別
  - レベル表示値
  - 譜面定数

## Update
- 楽曲および譜面情報の更新に関する要件。
- 運営者ページより、手動で更新用処理を呼び出す。
