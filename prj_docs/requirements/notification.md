# Notification Requirements

## Overview
- ユーザーへの通知（Notification）に関する要件を定義する。
- `overview.md`の「通知閲覧」機能に対応する。

## Notification Types
通知の対象となるイベントは以下の通りとする。
- 大会関連
  - 大会への参加が確定した
  - 参加している大会が開始した
  - 参加している大会が終了した
- 1v1関連
  - 1v1対戦への挑戦を受けた（対戦相手として指定された）
  - 自身が作成した1v1対戦に挑戦があった
  - 1v1対戦が成立した（挑戦の承認が確定した）
  - 参加している1v1対戦が終了した
- 運営からのお知らせ
  - 運営が全ユーザーまたは一部ユーザーに向けて配信するお知らせ。

## Notification Delivery
- 上記イベントの発生を契機として、対象ユーザーに通知が生成される。
- 運営からのお知らせは、全ユーザーに向けて一斉配信される。

## Viewing Notifications
- ユーザーは自身宛ての通知を一覧で閲覧できる。
- 通知には、発生したイベントの概要と、関連ページへのリンクが含まれる。

## Read / Unread State
- 各通知には未読/既読の状態がある。
- ユーザーが通知を閲覧することで、既読状態となる。

## Notification Settings
- ユーザーは通知設定（`user.md`の「User Settings」参照）により、通知の受け取り可否を変更できる。
