# System Overview

## Purpose
このドキュメントは、システムの全体像を把握するための概要を提供することを目的とする。

## Target Users
システムの対象ユーザーを記述する。
- エンドユーザー（SEGAの音楽ゲーム「オンゲキ」プレイヤー）
- システム管理者

## Core Features
ユーザーが利用できる主要な機能を記述する。
- ユーザー登録
- ログイン/ログアウト
- プロフィール管理
- 大会開催/参加
- 1v1対戦
- コースモード挑戦
- スコア提出
- ランキング閲覧
- 通知閲覧
- 各種設定管理

## Non-Goals
このシステムで対応しない機能や範囲を記述する。
- ゲームプレイ自体の提供（オンゲキの筐体でのプレイは含まれない）
- 外部SNSとの連携
- 課金機能
- 個人情報の取得

## Overall User Flow
ユーザーがシステムを利用する際の典型的なフローを記述する。
- ユーザー登録
- ログイン
- プロフィール管理
- 大会開催/参加
- 1v1対戦
- コースモード挑戦
- スコア提出
- ランキング閲覧
- 通知閲覧
- 各種設定管理

## Major Constraints
システム開発および運用における主要な制約を記述する。
- オンゲキの筐体との連携は行わないため、ゲームプレイ情報は外部の公式ユーザページ「オンゲキNET」から取得する必要がある
- 外部SNSとの連携は行わない
- 課金機能は提供しない
- 個人情報の取得は行わない
