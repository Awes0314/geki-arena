# Course Requirements

## Overview
- コースモード（Course）に関する要件を定義する。

## Course premise
- コースモードは、決められた複数の楽曲を連続してプレイし、スコアや判定などの結果で合格を目指すモードである。
- 運営者が事前に設定したコースをプレイすることが前提となる。
- 難易度の低いほうからCHAPTER1,2,3,...とし、各CHAPTERに複数のコースが存在する。
- 各コースは、複数の楽曲で構成される。

## Course Difficulty / Rank
- コースの難易度は、CHAPTERごとに設定される。
- 各コースには、クリア条件や合格判定が設定される。
- クリア条件は、コースごとに運営が個別に設定する（例: 各譜面のスコア閾値など）。全コース共通の統一基準は設けない。

## Challenge
- ユーザーは、運営者が設定したコースに挑戦することができる。
- 挑戦に手続きは不要で、いきなりの提出が可能である。

## Musics / Charts
- コースモードで使用される楽曲および譜面に関する要件を定義する。
- `musics_charts.md`参照。

## Score Submission
- コースモードにスコアを提出する場合、通常のブックマークレット提出を行う。
- プレイ履歴の取得時、同コースの楽曲は連続プレイである必要がある。

## Result
- コースモードの結果は、各楽曲のスコアや判定に基づいて集計される。
- 合格条件を満たした場合、コースクリアとなる。
- 合格条件を満たさなかった場合、コース失敗となる。

## Ranking
- コースモードのランキング表示は行わない。

## Course Completion
- コースモードにおいて、合格条件を満たした場合の状態を定義する。
- コースクリア時には、ユーザーに対して達成感を与える演出や報酬の付与が行われる。
- 報酬としてコースに対応するエンブレムSVGが付与される。
- エンブレムSVGは自身のプロフィールで確認できるほか、各ページのユーザを表す部分にも表示される。
