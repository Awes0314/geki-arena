# User Requirements

## User Profile
ユーザープロフィールを管理/閲覧する機能。

### Viewing Profile
ユーザーが自身/他のユーザーのプロフィールを閲覧する機能。
- プロフィールにはユーザーNo、表示名、アイコン、過去戦績、自己紹介、外部SNSリンク、Rating区分、コースバッジなどが含まれる。
- 他のユーザーのプロフィールも閲覧可能である（ログイン済みのユーザーのみ）。
- 過去戦績は、大会・1v1の機能実装後に表示する（それまでは枠のみ表示）。
- 削除済みのユーザーのプロフィールは表示しない。

### Editing Profile
ユーザーが自身のプロフィールを編集する機能。
- 編集可能な項目には表示名、アイコン、自己紹介、外部SNSリンク、Rating区分、コースバッジ表示/非表示などが含まれる。
- 表示名は1〜20文字、自己紹介は0〜500文字とする。
- アイコン画像はpng / jpeg / webpのいずれか、2MB以下とする。選択した画像は保存前に編集画面上のアイコン表示へ反映する。アイコンの削除も可能である。
- 外部SNSリンクはX・Discord・その他の3種類で、各1件まで設定できる（未入力は未設定）。
  - X: ユーザー名（`@`は付けても付けなくてもよい。英数字と`_`の1〜15文字）。入力値からXのプロフィールURLへのリンクとして表示する。
  - Discord: ユーザー名（`a-z`, `0-9`, `_`, `.`の2〜32文字、連続するピリオドは不可、小文字に正規化）。ユーザー名からはURLを生成できないため、リンクではなくテキストとして表示する。
  - その他: `https://`から始まるURL。
- 保存に成功した場合は、自身のプロフィール閲覧画面へ遷移する。
- ユーザーNoや過去戦績は編集できない。
- Rating区分は、外部データとの照合を行わないユーザーの自己申告（手動入力）による値である。
- コースバッジは、獲得済みバッジの中から表示する1件を選択する（複数同時表示は不可。未選択の場合は非表示）。

## User Settings
ユーザー設定を管理する機能。
- 編集可能な項目には通知設定、表示設定、アカウント設定、UI設定などが含まれる。

## Reporting
ユーザーが他のユーザーを報告する機能。
- 報告機能により、不適切な行動やコンテンツを運営に通知できる。
